Ограничения минимального варианта (MVP):

- В команде максимум 4 игрока.
- Присоединение только по короткому коду (формат: АБ-123).
- Чат, приглашения по ссылке и роли (капитан/игрок) не входят в MVP.
- Баллы за любую станцию суммируются в один общий счёт команды.
- Любой участник может отправить ответ на любой станции.
- Код команды многоразовый, действует до 4 успешных входов.
- После 4-го входа код автоматически аннулируется.
- Push-уведомления о входе игроков не реализуются.

Критерии готовности (Definition of Done):
- Код генерируется автоматически, состоит из 2 букв и 3 цифр.
- Система блокирует 5-го участника с ошибкой «Лимит команды исчерпан».
- Общий счёт на фронте обновляется в реальном времени без перезагрузки.
- При вводе неверного кода отображается ошибка «Код не найден или истёк».
