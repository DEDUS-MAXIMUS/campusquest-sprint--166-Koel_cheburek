# Начисление баллов и прогресс-бар

## Зачем нужна
Визуализировать успех студента и мотивировать пройти квест до конца.

## Пользовательский сценарий
1. Студент дает верный ответ на станции.
2. В правом верхнем углу увеличивается счетчик баллов (+10).
3. Внизу экрана заполняется полоска прогресса (1 из 8 станций пройдено).
4. При 100% появляется кнопка «Скачать сертификат».

## Критерий готовности
- Счетчик обновляется мгновенно без перезагрузки.
- Прогресс-бар пропорционален количеству пройденных станций.
- Сертификат генерируется с именем студента.

## Риск или вопрос
- Как считать прогресс, если станции можно проходить в любом порядке? (Решили: считать по количеству открытых, а не по порядку).
