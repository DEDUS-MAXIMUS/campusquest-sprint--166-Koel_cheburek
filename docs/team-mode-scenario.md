# Team Mode Scenario

## Пошаговый сценарий команды из 4 игроков

| Шаг | Действие | Результат |
|---|---|---|
| 1 | Игрок 1 нажимает «Создать команду» | Команда создана, игрок 1 — участник №1 |
| 2 | Система выдаёт код команды (6 символов) | Код виден создателю |
| 3 | Игроки 2–4 вводят код и присоединяются | В команде до 4 участников |
| 4 | Любой участник открывает станцию и вводит ответ | Ответ засчитывается команде |
| 5 | Команда видит общий счёт и прогресс | Итоговый результат по станциям |

## Вне минимального варианта
- чат
- приглашения по ссылке
- отдельные роли
- push-уведомления

## DoD
- Создатель получает код.
- Присоединение по коду до 4 игроков.
- 5-й игрок получает сообщение «Команда заполнена».
- Любой участник может отправить ответ.
- Повторный ответ на станцию не дублирует баллы.
- Общий счёт виден всем участникам.
