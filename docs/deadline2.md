# CQ4 — Карточка станции с загадкой

## Зачем нужна
Карточка — ядро квеста: на станции игрок видит название, короткую историю и загадку, без неё прохождение невозможно.

## Пользовательский сценарий
1. Игрок открывает доступную станцию из списка.
2. Видит название станции, короткую историю и текст загадки.
3. Переходит к полю ответа.

## Критерий готовности
- На карточке есть название, история и загадка.
- Карточка открывается только для доступной станции.
- Текст читается на экране без прокрутки вбок.

## Риск или вопрос
- Нужна ли картинка на карточке в первом MVP или можно только текст?
